# IT Simplification Use Cases

## Purpose

Identify communication activities that could be partially or fully automated.

---

## Use Case 1 - Weekly IT Simplification update

### Audience

IT Leadership Team

### Current process

Manually review dashboard and reporting data.

Manually write update.

### Desired outcome

Generate a first draft automatically.

### Inputs

- Dashboard data
- Savings information
- Weekly progress updates

### Outputs

- Weekly summary email
- Leadership update

---

## Use Case 2 - Executive summary

### Audience

Executive Leadership Team

### Current process

Manual preparation of status summaries.

### Desired outcome

Generate concise executive-ready summaries.

### Inputs

- Dashboard metrics
- Key achievements
- Risks and issues

### Outputs

- Executive summary
- Talking points

---

## Use Case 3 - Monthly reporting

### Audience

Senior Management

### Current process

Manual preparation of monthly reporting packs.

### Desired outcome

Automatically generate reporting content.

### Inputs

- Monthly dashboard metrics
- Savings achieved
- Forecast data

### Outputs

- Monthly report
- Management presentation content
