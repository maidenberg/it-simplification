# User story

## As a

Project Manager

## I want

To generate a first draft weekly IT simplification update automatically

## So that

I spend less time writing updates and more time analysing insights.

## Acceptance criteria

1. User uploads or provides a source spreadsheet.
2. System extracts key metrics.
3. System generates executive-friendly commentary.
4. System creates a draft update.
5. User reviews and edits before distribution.

## Definition of done

A weekly update can be generated in under one minute.
