# IT Simplification MVP

## Goal

Produce a first draft weekly IT Simplification update automatically.

## User

Project Manager

## Input

A spreadsheet containing:

- Vendor savings
- Cost-out figures
- Progress updates
- Risks and issues

## Process

1. Read source data.
2. Calculate key changes from previous week.
3. Identify major movements.
4. Generate narrative commentary
5. Produce draft update.

## Output

### Executive summary

One paragraph summary.

### Key metrics

- Savings achieved
- Savings forecast
- Major opportunities
- Major risks

### Highlights

Three to five key achievements.

### Risks

Open risks and blockers.

### Next steps

Planned activities for next week.

## Success criteria

The generated output requires less than five minutes of editing before distribution.
